# Rally — Pong

A responsive, single-player Pong game with an adaptive CPU opponent. No build step or dependencies are required.

## Play

Open `index.html` in a modern browser, or serve this folder with any static file server.

- Move your paddle with **W / S** or **↑ / ↓**.
- Press **Space** to pause or resume.
- On touch screens, drag on the court to move.
- First to **7** points wins. Use **Reset** to start a fresh match.
